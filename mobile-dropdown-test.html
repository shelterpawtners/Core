🧪 Testing Instructions

Mobile View Testing:

  1. Resize Window: Make your browser window narrow (under 768px wide) OR view on mobile device
  2. Find Hamburger Menu: Look for the white hamburger icon with border in the top-right
  3. Open Menu: Click/tap the hamburger to open mobile navigation
  4. Test Dropdowns: Click "How It Works ▼" to see submenu expand
  5. Check Subpages: Verify you can see: How It Works, About Us, Contact, FAQ
  6. Test Auth Menu: If authenticated, test "My Account ▼" dropdown
  7. Close Menu: Click hamburger again or select a menu item
